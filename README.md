# Java Control Flow Examples

This repository contains simple Java programs demonstrating basic **control flow statements and loops**.

## Topics Covered

* **If-Else** – Decision making using conditions
* **Switch** – Selecting between multiple cases
* **For Loop** – Repeating a block of code a fixed number of times
* **While Loop** – Repeating code while a condition is true

## Purpose

These examples are created for practicing the fundamentals of **Java programming, conditions, and loops**.
